# Kiyamu — සිංහල සංවර්ධක මාර්ගෝපදේශය

[ප්‍රධාන README](../../README.md) · [English developer documentation](README.md)

## ව්‍යාපෘතිය ගැන

Kiyamu යනු AsTeRICS AAC මත පදනම් වූ සන්නිවේදන සහායක යෙදුමකි. මෙහි Vue 2.7, JavaScript, Webpack සහ PouchDB භාවිත වේ. සිංහල අතුරුමුහුණත සහ සන්නිවේදන පුවරු තවම සකස් කළ යුතුය.

## දේශීයව ක්‍රියාත්මක කිරීම

Node.js 22 සහ Yarn ස්ථාපනය කරන්න. පවතින CI සැකසුම ද Node.js 22 භාවිත කරයි. ව්‍යාපෘති ෆෝල්ඩරය තුළ:

```sh
yarn install
npm run start
```

ඉන්පසු http://localhost:9095 විවෘත කරන්න. Windows PowerShell මඟින් npm.ps1 අවහිර කළහොත් npm.cmd run start වැනි ආකාරයෙන් npm.cmd භාවිත කරන්න.

## පරීක්ෂණ සහ build

```sh
npm test -- --runInBand
npm run build
```

පළමු විධානය Jest පරීක්ෂණ ක්‍රියාත්මක කරයි. දෙවන විධානය පරීක්ෂණ ක්‍රියාත්මක කර, app/build තුළ නිෂ්පාදන ගොනු සකස් කර, service worker cache ලැයිස්තුව යාවත්කාලීන කරයි. ජනනය කළ ගොනු සෘජුව සංස්කරණය කිරීම වෙනුවට src තුළ වෙනස්කම් කරන්න.

## සිංහල සඳහා දායක වීම

- අතුරුමුහුණතේ පරිවර්තනය, පුවරුවල වචන සහ හඬ යන කොටස් තුන වෙන වෙනම සලකා බලන්න.
- app/lang/i18n.en.json හි පවතින keys සහ භාෂා තේරීමේ සැකසුම් පරීක්ෂා කරන්න. නව සිංහල JSON ගොනුවක් එක් කිරීම පමණක් ප්‍රමාණවත් යැයි නොසලකන්න.
- ගොනු UTF-8 ලෙස සුරකින්න. සිංහල අකුරු සහ පිලි පරිගණකයක සහ ජංගම උපාංගයක නිවැරදිව පෙන්වන බව පරීක්ෂා කරන්න.
- කෙටි, පැහැදිලි වචන භාවිත කරන්න. භාවිත කරන්නන්ගේ සහ ඔවුන්ට සහාය දෙන අයගේ අදහස් ලබාගන්න.
- උපාංගයේ සිංහල TTS හඬක් තිබේදැයි පරීක්ෂා කරන්න. හඬ ලැයිස්තුවේ si-LK සඳහන් වීම පමණක් සෑම උපාංගයකම සිංහල හඬ ක්‍රියා කරන බව තහවුරු නොකරයි.
- අන්තර්ජාලය නොමැති විට හඬ සහ පුවරු ක්‍රියා කරන ආකාරය ද පරීක්ෂා කරන්න. බාහිර TTS සේවාවකට අන්තර්ජාල සම්බන්ධතාව අවශ්‍ය විය හැක.
- යතුරුපුවරුව, touch සහ scanning භාවිතයේදී ප්‍රවේශ පහසුකම් බිඳ නොවැටෙන බව තහවුරු කරන්න.

## වෙනස්කම් ඉදිරිපත් කිරීම

එක් වෙනස්කමකට අදාළ branch එකක් සහ pull request එකක් භාවිත කරන්න. විසඳන ගැටලුව, වෙනස්කම සහ පරීක්ෂා කළ ආකාරය සඳහන් කරන්න. දෝෂ වාර්තාවකට නැවත දෝෂය ඇති කරන පියවර, උපාංගය, මෙහෙයුම් පද්ධතිය සහ බ්‍රවුසරය ඇතුළත් කරන්න. පෞද්ගලික දත්ත හෝ මුරපද එක් නොකරන්න.
